# uni-ders-notu-hesaplayici
Vize ve final notuna göre ders not ortalamasını, harf notunu ve gerekli büt notunu hesaplayan basit python uygulaması.
Bu proje Python öğrenme sürecimde yazdığım ikinci uygulamadır.
## Özellikler
* Vize ve final notlarına göre ortalama ve harf notu hesaplar.
* Kaldığınız dersler için BÜT sınavından almanız gereken minimum puanı gösterir.
* Hatalı ve mantıksız veri girişlerini (harf/yazı) engelleyen kontrol mekanizmasına sahiptir.
